Page 04 · How we work

今后怎么做

对照数字在案例页。社区 C 已经把中奖重复率从 57.94% 降到 34.48%，排期时优先复用能换血的玩法。

A

人数差最大

先做一键完成

四个社区对过一遍：投票、抽奖、名片、打卡、H5 这类低门槛，场均大约两千人；截图征集 / 创作大约五十人。日常促活优先「点一下就完成」，别一上来就布置作业。

B

排期

月度骨架先钉住

抽奖周常、积分商城、名片更新、茶话会，是最稳的人数底座。把它们排成每月骨架，空档用话题讨论填，不要连续两周都上高成本征集。

C

别拿来考大盘

UGC 留给大节点

内容征集十二场，场均只有八十人左右。创作适合沉淀素材、找核心作者，不适合当大盘人数指标。小节点改投票讨论，大版本再开投稿。

D

消息量

刚需社交比求分享香

社区 D 的 H5 集换卡 919 人里，93.7% 是玩家自己把链接发出去的。换卡、集卡、名片打卡会自己把人拉进频道；「请发一篇攻略」常常冷场。能做成收集、站队、接力的，就别做成命题作文。

D

可统计

预热做成 Bot 闯关

社区 D 版本解谜单场 3,948 条消息；情报匣 1,153 次交互、成功 501、成功率 43.45%，消息 / 反应较上周 +147% / +302%。发预热帖只能看浏览；Bot 谜题能记下谁解出来了，版更节点优先复用。

B

分区

同一套玩法要分轨

日区更吃投票和轻点击，繁中更能撑留言和共创。奖励、题目、完成方式拆开写，比两区共用一份作业省事，也更准。

C

社区 C 已验证

中奖名单要换血

社区 C 针对获奖重复度高改了活动设计。7 月下旬策略生效后，发放 58 人次、去重 38 人，中奖重复率从 57.94% 降到 34.48%（-23.46pt，相对 -40.49%）。每赛季给未中奖的人一场破冰局，别把奖反复发给熟面孔。

A

边际递减

召回别反复吃老本

邮箱绑定、截图回传这类作业，第一次很亮，再做会明显变少。社区 D 二期加上里程碑奖池，同期回传才从 164 拉到 321（+95.7%）。同一条链路最多用一两个版本节点，后面改端内完成或换奖励，不要连做三轮还不改规则。

C

口径

浏览量要一起记

一百八十九场里，超过一半缺浏览人数，参与率就没法横比。每场至少记下浏览、参与人数、互动；人数只看参与，别把曝光加进去。

D

效率

爆款做成模板再复用

节日礼包、身份点击、名片更新、H5 集卡，高峰月已经验证过。低谷月用周常托底，把爆款拆成可复制模块，比每次从零想主题更省运营时间。
